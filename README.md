# ⚡ ElectroKit — Offline Electronics Toolkit (v4.0.0)

[![Kotlin](https://img.shields.io/badge/Language-Kotlin%202.0-7F52FF?style=for-the-badge&logo=kotlin)](https://kotlinlang.org/)
[![Jetpack Compose](https://img.shields.io/badge/UI-Jetpack%20Compose-4285F4?style=for-the-badge&logo=jetpackcompose)](https://developer.android.com/jetpack/compose)
[![Version](https://img.shields.io/badge/Version-v4.0.0-10B981?style=for-the-badge&logo=github)](https://github.com/dk2017044/ElectroKit/releases)
[![License](https://img.shields.io/badge/License-MIT-00E5FF?style=for-the-badge)](LICENSE)

**ElectroKit** is a modern, high-performance, offline Android application engineered for electronics engineers, students, hobbyists, and technicians. Designed with Material You dynamic accent themes, glassmorphic UI cards, real-time circuit wave animations, and an offline database of 400+ component datasheets.

---

## ✨ Key Features in v4.0.0

### 🌟 Non-Stop Glowing Glassmorphic Card Shimmer
- Continuous, infinite accent shimmer gradient sweep across all cards across all 12 screens.
- Seamless lighting effect without pitch-black transitions or fade-offs.

### ⚡ 12-Point ElectroKit Electric Sparks Splash Screen
- Modern startup animation featuring an integrated "E" & "K" circuit logo with radiating 8-directional electric sparks and orange lightning bolt energy pulses.
- Fully adapted to the user's active Accent Color theme.

### 👤 Profile & Personalization Greeting
- Time-aware dynamic header greeting (`Good Morning / Afternoon / Evening, Dilip 👋`) with live typewriter typing effect and customizable user profile name (16-char max input).

### 🔲 Glassmorphic Accent Highlight Inputs & Search Bars
- Customized input fields, search bars, unit dropdown selectors, and filter chips with 1.dp accent border highlights and semi-transparent surface containers.

### 📦 Expanded Components DB Catalog
- Re-seeded native SQLite database containing 400+ datasheets, pinout diagrams, maximum ratings, equivalent parts, and application notes.

### 🌊 Subtle Ambient PCB Wave Background
- Smooth 5-trace circuit board background with soft, non-disturbing animated cyan & accent signal pulses.

### 🔄 In-App One-Click Auto Update Manager
- Automated GitHub Release fetcher with silent background downloading, progress tracking, and APK installer integration.

---

## 🛠️ Built With

- **Language**: Kotlin 2.0.0
- **UI Framework**: Jetpack Compose + Material 3
- **Architecture**: MVVM + Clean Architecture
- **Database**: Native SQLite (`ElectroKitOpenHelper`) + Room
- **Async & Reactive**: Kotlin Coroutines & StateFlow
- **Graphics**: Compose Canvas & Infinite Transition Animation Shaders
